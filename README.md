# MTG Commander

A Magic: The Gathering **Commander** virtual tabletop for you and your friends: 2–6 players, online or on one computer.
This repository only holds the downloadable releases.

> Unofficial fan project. Not affiliated with or endorsed by Wizards of the Coast. Card names, art and text belong to their owners. Non-commercial.

## Download and play (Windows 10/11)

1. Go to **https://github.com/sildatema/mtg-releases/releases/latest** and download **`MtgCommander-win-Setup.exe`**.
2. Run it. Windows may say *"Windows protected your PC"*: click **More info** → **Run anyway**. The game isn't code-signed, and you only see this once.
3. It installs in a few seconds, with no admin rights needed. Always start the game with the **MTG Commander** shortcut on your desktop or in the Start menu.

Updates are automatic: the game checks when it starts. Small updates download while you play and are installed the next time you start it. For a big update (needed to keep playing online) it asks *"Update now?"*. Say yes: older versions can't join games on the new server. The menu screen shows which version you have.

To play online, ask the host for the server address (and password, if any), then *Connect to server* on the menu. To uninstall: Windows Settings → Apps → MTG Commander → Uninstall.
